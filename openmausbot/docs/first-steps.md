# Primeiros passos

1. **Pegue o código.** Abra o log do app e copie o código da linha `pairing code` (uso único, vale 5 minutos). A linha `open or scan` traz o link completo.
2. **Pareie o navegador.** Abra `<endereço do app>/pair`, digite o código e confirme. Código errado ou vencido é recusado; um código só vale uma vez.
3. **Entre no Claude e no Codex.** *Configurações > IA > Engines*:
   - *Claude*: o botão de login abre a página da Anthropic; copie o código que ela mostrar e cole de volta no app.
   - *Codex*: o app mostra um código de uso único para digitar na página da OpenAI (o login por código de dispositivo precisa estar ativo na segurança da conta do ChatGPT).
   - Com chave de API em vez de conta pessoal: *Configurações > Conexões > Model providers*.
4. **Crie bots e converse.** Cada bot usa o Claude ou o Codex com o seu login. Rotinas agendadas continuam rodando com o navegador fechado.

## Outro dispositivo
Reinicie o app (cada início imprime um código novo) ou use *Phone apps* nas configurações. Só um navegador pareado com acesso total vê as configurações.

## Atualizar e voltar
Os pacotes estão fixados no template; uma versão nova do template troca as versões. A plataforma tira um snapshot antes de atualizar, e voltar a versão leva os dados junto.
