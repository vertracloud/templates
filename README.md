## English

The catalog of one-click templates for [Vertra Cloud](https://vertracloud.app): software ready to run (n8n, OpenClaw, Hermes Agent, Evolution API, Open WebUI, Uptime Kuma) and starter projects (Discord bots in JavaScript and Python). Each folder is one template: a manifest, the code or the Dockerfile, a README in three languages, docs and an icon.

| Template | Type | What it is |
|---|---|---|
| [`n8n`](n8n/) | code (Node.js 24) | Workflow automation; Code node in JavaScript, queue mode, community nodes |
| [`openclaw`](openclaw/) | code (Node.js 24) | Personal AI assistant with browser, panel and channels |
| [`hermes-agent`](hermes-agent/) | code (Python 3.14) | AI agent with browser chat and channels |
| [`evolution-api`](evolution-api/) | image (own Dockerfile) | WhatsApp API with Postgres |
| [`open-webui`](open-webui/) | image (own Dockerfile) | AI chat interface (bring your own key) |
| [`uptime-kuma`](uptime-kuma/) | image (own Dockerfile) | Monitoring and status pages |
| [`discord-bot-js`](discord-bot-js/) | code | Discord bot starter (discord.js) |
| [`discord-bot-python`](discord-bot-python/) | code | Discord bot starter (discord.py) |

### Layout
```text
<template>/
  vertracloud.template.yaml   manifest
  README.md  README.en.md  README.es.md
  docs/                       _index.json + pages (first-steps, reference)
  icon.svg | icon.png
  docker/                     image templates: Dockerfile and what it copies (source.context)
  src/                        code templates: the project (source.path)
schema/v1.json                JSON Schema of the manifest, generated by the platform
scripts/validate.mjs          schema + semantic rules + folder rules
scripts/pack.mjs              packs the folders into the platform's import format + catalog/index.json
scripts/lib/                  checks and the capability scanner
scripts/image-check.sh        builds a template image and scans it for file capabilities
.github/workflows/ci.yml      validate, build and scan the image, pack and upload on merge
catalog.json                  catalog flags that are not in the manifest (featured, visibility)
ICONS.md                      where every icon comes from and the rule that applies
```

### Commands
```bash
npm ci
npm run validate                    # every template
npm run pack -- --out dist          # dist/packages/<id>/<version>.zip and dist/catalog/index.json
npm test                            # tests of the checks
./scripts/image-check.sh uptime-kuma   # build and scan one template image (needs Docker)
```
To contribute a template, read [CONTRIBUTING.md](CONTRIBUTING.md). The manifest format is documented in the Templates tab of the Vertra Cloud docs.

## Português (Brasil)

O catálogo de templates de 1 clique da [Vertra Cloud](https://vertracloud.app): softwares prontos para rodar (n8n, OpenClaw, Hermes Agent, Evolution API, Open WebUI, Uptime Kuma) e projetos iniciais (bots de Discord em JavaScript e Python). Cada pasta é um template: manifesto, código ou Dockerfile, README em três idiomas, docs e ícone.

A tabela, a estrutura de pastas e os comandos acima valem aqui. Para contribuir com um template, leia o [CONTRIBUTING.md](CONTRIBUTING.md) (há uma seção em português). O formato do manifesto está documentado na aba Templates da documentação da Vertra Cloud.

Nomes e logos de produtos pertencem aos seus donos e aparecem só para dizer o que o template empacota; veja o [ICONS.md](ICONS.md).
